# Ask the Theory

This work is multidisciplinary — physics, clinical psychology, mathematics, neuroscience.
If you are not specialist in all of it, start by asking it a question directly.

**How:**
1. Copy the paper most relevant to your question (links in the table above)
2. Open [Claude](https://claude.ai) or [ChatGPT](https://chatgpt.com) (whichever you already use)
3. Paste the PDF text, then type your question

The papers are written to be queryable this way. The omnibus contains everything but is large — for a focused question, a single paper works better.
